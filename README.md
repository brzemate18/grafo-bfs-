# grafo-bfs-
Implementação do algoritmo BFS (Breadth-First Search) utilizando grafos em Python. O projeto demonstra a busca em largura percorrendo os nós por níveis com uso de filas. Inclui criação de grafos, arestas e visualização da ordem de visita dos vértices. Ideal para estudos de algoritmos, lógica e estruturas de dados.
